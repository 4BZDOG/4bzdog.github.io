About

Every project started as a problem in a real classroom.

A concept that wouldn't click, a worksheet that took an hour to make, a room that kept getting louder. Each of these tools began as one of those, got built to fix it, and then kept growing.

  • Browser first. Nothing to install. Most of these work offline once they've loaded.
  • Made for NSW. Aligned to NESA syllabus outcomes, command verbs and band descriptors.
  • Built in the open. Every line is on GitHub, and this page rebuilds itself from it.
